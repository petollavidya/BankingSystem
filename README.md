**Banking Dashboard System**
**Overview**

The Banking Dashboard System is a full-stack web application that simulates basic banking functionalities. It allows users to securely log in to their accounts, manage transactions, and explore investment options such as stocks, mutual funds, and precious metals. The system is designed to provide a simple and interactive interface for managing personal banking activities.

**Features**
**User Authentication**

Users can log in securely using their credentials. User account information is stored in the database.

**Account Management**

After logging in, users can view their account details and manage their balance.

**Deposit and Withdrawal**

Users can deposit money into their account or withdraw funds directly through the dashboard.

**Transaction History**

All transactions performed by the user are stored in local storage and displayed in the transaction history section so users can track their activities.

**Investment Options**

The dashboard also allows users to explore investment options, including:

**Stock market investments**

**Mutual funds**

**Buying gold or silver coins**

**User Data Storage**

User account information and login credentials are stored in a MongoDB database.

**Tech Stack**

**Frontend**: HTML, CSS, JavaScript

**Backend**: Node.js, Express.js

**Database**: MongoDB

**Storage**: Local Storage (for transaction history)

**Purpose**

The purpose of this project is to demonstrate the development of a banking-style dashboard with authentication, transaction management, and investment features while gaining experience with full-stack web technologies.
